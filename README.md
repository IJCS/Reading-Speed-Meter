# Reading Speed Meter

## About App
A lightweight, web-based tool designed to help users measure their reading speed accurately across different languages. By performing multiple tests, users can determine their real average reading speed in words per minute (WPM).

## How to Use

1. Select your Language
2. Start the Test (With the spacebar or the button)
3. Read the text
4. Finish the test (With the spacebar or the button)

* Track Results in your __History__
* Get your new **Average WPM** after each test
* Repeat as many times as necessary to ensure a correct average

## About example texts
Originally, I considered using public domain literature for the reading samples. However, to ensure 100% compliance and avoid any copyright ambiguities, I decided to use AI-generated texts.
